# Sarah Johnson profile — vanilla HTML/CSS/JS

## Run
Open `index.html` in a modern browser. No build tool, package manager, or server is required.

## Files
- `index.html` — semantic page structure
- `styles.css` — responsive styling
- `script.js` — profile data, tabs, highlight viewer, post dialog, and message form validation

## Notes
- Images and the Geist font are loaded from external URLs, so those require an internet connection.
- The message form is a front-end demo only. It validates input and shows a confirmation state, but does not send or store messages. Connect a backend/email service to make delivery real.
- Original animation and icon libraries were replaced with CSS transitions, text symbols, and vanilla JavaScript.
